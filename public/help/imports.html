Import Help

Understanding BubbleList import formats and options

Supported File Formats

JSON Format

Use for: Full backups, folder structures, or complete template exports

  • Preserves complete hierarchy including folders, items, and shopping sessions
  • Maintains all metadata (categories, sort order, quantities, etc.)
  • Can import entire folder structures or individual templates
  • Auto-renames duplicates to prevent conflicts
{ "name": "Grocery Store", "type": "template-folder", "items": [ { "name": "Produce", "type": "category", "items": [ { "name": "Apples", "type": "item", "defaultQuantity": "2 lbs" } ] } ] }

TXT Format

Use for: Simple item lists, quick imports, or creating new shopping lists

  • One item name per line
  • Items are automatically categorized
  • Duplicate items are skipped
  • Blank lines are ignored
Apples Bananas Milk Bread Eggs

CSV Format

Use for: Structured imports with categories and quantities

  • Columns: name, category, sortOrder, defaultQuantity
  • Header row is optional (auto-detected)
  • Missing categories are auto-assigned
  • Duplicate items are skipped
name,category,sortOrder,defaultQuantity Apples,Produce,1,2 lbs Bananas,Produce,2,1 bunch Milk,Dairy,1,1 gallon

Import Contexts

Top-Level Import

Import from the main dashboard (no folder selected):

  • JSON: Imports full backup with all folders and templates
  • TXT/CSV: Creates a new shopping list at the root level

Folder Import

Import into an organizational folder:

  • JSON only: Imports folder structure with sub-folders and templates
  • Existing items are preserved (never overwritten)

Template Import

Import into a template folder (shopping list):

  • JSON: Imports template items with full metadata
  • TXT/CSV: Appends items to the existing list
  • Duplicate items (by name) are automatically skipped

Common Questions

What happens to duplicate items?

Items with identical names are skipped during import. You'll see a summary of skipped duplicates after import completes.

What happens to duplicate folders?

Folders with the same name are automatically renamed with a numbered suffix: (1), (2), (3), etc.

Can I undo an import?

Imports cannot be undone automatically. However, since imports never overwrite existing data, your original items remain intact. You can manually delete imported items if needed.

What's the maximum file size?

Import files are limited to 10 MB. This is sufficient for thousands of items and hundreds of folders.
