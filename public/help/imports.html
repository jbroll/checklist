Understanding CheckList import formats

Supported File Formats

Text Format (.txt)

Use for: Simple item lists or hierarchical lists with categories

  • One item per line
  • Use indentation (spaces or tabs) to create categories
  • Indented items become children of the item above
  • Blank lines and lines starting with # are ignored
Produce Apples Bananas Oranges Dairy Milk Cheese Yogurt Bakery Bread

CSV Format (.csv)

Use for: Spreadsheet imports

  • Two columns: category and item
  • Header row is optional
  • Duplicate items are skipped
category,item Produce,Apples Produce,Bananas Dairy,Milk Dairy,Cheese

JSON Format (.json)

Use for: Full backups and restoring exported lists

  • Preserves complete hierarchy including folders and items
  • Maintains all metadata
  • Auto-renames duplicates to prevent conflicts

Import Contexts

Top-Level Import

Import from the main screen (no list selected):

  • TXT/CSV: Creates a new list at the root level
  • JSON: Imports full backup with all folders and lists

List Import

Import into an existing list:

  • TXT/CSV: Appends items to the existing list
  • JSON: Imports items with full metadata
  • Duplicate items (by name) are automatically skipped

Common Questions

What happens to duplicate items?

Items with identical names are skipped during import. You'll see a summary of skipped duplicates after import completes.

What happens to duplicate folders?

Folders with the same name are automatically renamed with a numbered suffix: (1), (2), etc.

Can I undo an import?

Imports cannot be undone automatically. However, since imports never overwrite existing data, your original items remain intact.

What's the maximum file size?

Import files are limited to 10 MB.
