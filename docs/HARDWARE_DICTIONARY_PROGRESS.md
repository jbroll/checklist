### Priority Categories for Expansion

Based on the gap analysis, these categories need the most work:

1. **Plumbing Pipe & Fittings** (-100): PVC, copper, PEX, brass, CPVC, ABS + all fitting types

4. **Fasteners/Bolts** (-65): More bolt varieties needed
5. **Fasteners/Anchors** (-50): Specialty anchors for different materials
6. **Lighting Fixtures** (-50): Chandeliers, pendants, flush mounts, etc.
