# Kjekit Brand Guide

## Brand Name

**kjekit** (lowercase, one word)

## Name Origin & Meaning

Kjekit is a playful fusion of two concepts:

1. **kjekt** (Norwegian) — "nice", "fun", "pleasant"
2. **check it** (English) — an action phrase, evoking checking items off a list

The name captures both the experience (enjoyable, pleasant) and the action (checking things off).

## Pronunciation

**"check-it"** /ˈtʃek.ɪt/

The Norwegian "kj" sound is similar to the English "ch" sound, making the pronunciation intuitive once explained.

### Pronunciation Guidance for Users

- First-time display: `kjekit (check-it)`
- Audio pronunciation in onboarding
- Tagline reinforcement: "Say it like 'check it'"

## Brand Voice & Tone

### Personality Traits

- **Friendly** — Approachable, never intimidating
- **Playful** — Light-hearted, enjoys the wordplay
- **Efficient** — Respects users' time
- **Scandinavian-inspired** — Clean, minimal, thoughtful

### Writing Style

- Casual but clear
- Short sentences
- Action-oriented
- Occasional wordplay with "check" and "kjekt"

### Examples

| Instead of... | Write... |
|---------------|----------|
| "Your items have been successfully added to the list" | "Added! Check it off when you're ready" |
| "No items in your shopping session" | "Nothing to check yet" |
| "Delete this item?" | "Remove from list?" |

## Visual Identity Concepts

### Logo Direction

The logo should subtly incorporate a **checkmark** element:

- **Option A**: The "k" forms a checkmark shape
- **Option B**: The dot on the "i" is a checkmark
- **Option C**: A speech bubble with checkmark (emphasizing "check it!" as exclamation)

### Color Palette

Scandinavian-inspired, clean and fresh:

```
Primary:    #2563EB (Blue) — Trust, clarity
Secondary:  #10B981 (Green) — Success, completion, checkmarks
Accent:     #F59E0B (Amber) — Warmth, friendliness
Background: #FAFAFA (Off-white) — Clean, minimal
Text:       #1F2937 (Dark gray) — Readable, not harsh
```

### Typography

- **Headings**: Clean sans-serif (Inter, Manrope, or similar)
- **Body**: Same family, lighter weight
- **Logo text**: Custom or geometric sans-serif

### Design Principles

1. **Whitespace** — Scandinavian minimalism
2. **Clarity** — Every element has purpose
3. **Delight** — Small moments of joy (micro-animations on check)
4. **Accessibility** — High contrast, clear touch targets

## Brand Usage Guidelines

### Do
- Use lowercase "kjekit" in running text
- Include pronunciation guide on first encounter
- Pair with tagline when space allows
- Use the checkmark motif consistently

### Don't
- Capitalize as "Kjekit" or "KJEKIT" (except sentence start)
- Separate as "kjek it" or "kje-kit"
- Use without pronunciation context for new users
- Overuse Norwegian — keep it accessible
