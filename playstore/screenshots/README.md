# Play Store Screenshots

## Specifications

- **Dimensions**: 1080x1920 (portrait) or 1920x1080 (landscape)
- **Format**: PNG or JPG
- **Min/Max**: 2-8 screenshots
- **Aspect ratio**: 16:9

## Naming Convention

```
01-dashboard.png
02-editor.png
03-shopping.png
04-sharing.png
05-dark-mode.png
06-profile.png
```

## Capture Command

```bash
adb exec-out screencap -p > 01-dashboard.png
```
