# Play Store Screenshots

## Specifications

- **Format**: PNG or JPEG (PNG recommended)
- **Size**: Min 320px, max 3840px per side
- **Aspect ratio**: Between 16:9 and 9:16
- **Count**: 2-8 screenshots required

Use native device resolution (e.g., 1080x2400 for modern Android phones).

## Naming Convention

```
01-tree-view-folders.png
02-tree-view-items.png
03-shopping.png
04-sharing.png
05-dark-mode.png
06-profile.png
```

## Capture Command

```bash
adb exec-out screencap -p > 01-tree-view-folders.png
```
