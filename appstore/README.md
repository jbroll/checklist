# Apple App Store Assets

## Required Files

| File | Dimensions | Format | Notes |
|------|------------|--------|-------|
| `icon-1024x1024.png` | 1024x1024 | PNG | No transparency, no rounded corners |

## Screenshots

Multiple device sizes required. Place in appropriate subfolder.

### iPhone 6.5" Display (Required)

Folder: `screenshots/iphone-6.5/`

- **Dimensions**: 1284x2778 (portrait) or 2778x1284 (landscape)
- **Devices**: iPhone 14 Plus, iPhone 13 Pro Max, iPhone 12 Pro Max

### iPhone 6.7" Display (Required for newer devices)

Folder: `screenshots/iphone-6.7/`

- **Dimensions**: 1290x2796 (portrait) or 2796x1290 (landscape)
- **Devices**: iPhone 15 Pro Max, iPhone 15 Plus, iPhone 14 Pro Max

## Screenshot Requirements

- **Format**: PNG or JPG
- **Required**: Minimum 2, maximum 10 per device size
- **Content**: Must be actual app screenshots (no marketing text overlay required)

## Recommended Screenshots

1. Tree view with folder tree
2. Tree view with items and categories
3. Shopping session view
4. Sharing/collaboration
5. Dark mode
6. Profile/settings
